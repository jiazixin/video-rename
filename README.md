# video-rename

[English](README.en.md)

在浏览器里整理本地视频、图片和音频。你可以浏览与播放媒体、手动改名，或让视觉模型根据视频截图生成中文文件名；也可以批量抽帧、给图片和音频编号、设置定时任务、查看处理记录和模型用量。

应用由 Go 服务、Vue 页面和 SQLite 组成，构建后只需一个可执行文件。支持 macOS 和 Linux，适合个人或受信任团队使用，只有一个管理员账号。

## 快速开始

从源码构建需要 Go **1.27.1**、Node.js **22.12 或更高版本**和 npm。抽帧与自动命名还需要 `ffmpeg`、`ffprobe` 在 PATH 中；自动命名需要支持图片输入的 OpenAI 兼容或 Anthropic 服务。浏览和手动改名无需模型服务。

在仓库根目录运行：

```bash
npm --prefix web ci
npm --prefix web run build
go build -o bin/video-rename ./cmd/video-rename
cp configs/config.example.yaml configs/config.local.yaml
chmod 600 configs/config.local.yaml
```

编辑 `configs/config.local.yaml`，填写实际媒体目录和密码：

```yaml
listen: "127.0.0.1"
port: 8790
media-path: "/srv/videos"
storage: "../data"
tmp-storage: "../.cache"
auth:
  username: "admin"
  password: "请替换为你的密码"
```

媒体目录必须已经存在；配置、数据和缓存目录必须位于媒体目录之外。示例密码不能用于启动。配置中的相对路径以配置文件所在目录为基准，不读取环境变量覆盖。

```bash
./bin/video-rename --config configs/config.local.yaml
```

打开 [http://127.0.0.1:8790](http://127.0.0.1:8790)，用配置中的账号登录。默认配置入口是 `configs/config.local.yaml`；其他参数见 `./bin/video-rename --help`，构建身份见 `--version`。

## 第一次使用

1. 在“文件目录”浏览媒体。首次打开目录会建立索引，刷新后显示完整列表。
2. 手动改名或编号前先检查选择范围。编号提供预览；改名不覆盖已有文件，可在记录中还原符合条件的改名。
3. 自动命名前，在“系统设置 → Prompt配置”准备提示词，再到“模型配置”填写地址、模型和密钥。先用少量视频验证质量和费用。
4. 在文件目录选择视频或目录，启动抽帧或命名；在“批次记录”查看进度、暂停或取消；详情按目录集中显示原名、新名和全部尝试历史，可筛选最终失败文件。在“运行记录”查看改名历史与失败诊断。

| 功能 | 说明 |
| --- | --- |
| 媒体预览 | 视频、音频使用浏览器原生解码，支持进度跳转；图片可连续浏览，不提供服务端转码 |
| 处理标记 | 保护已有名称；标记过的图片和音频跳过编号，标记过的视频跳过普通自动命名 |
| 独立抽帧 | 不改名；截图可供后续命名复用 |
| 计划管理 | 按目录和时区安排定时命名或抽帧；停机期间错过的计划不补跑 |
| 用量与分析 | 查看请求用量、耗时、失败原因；缺少模型 usage 时只估算文字 token，不含图片 |

后台索引扫描默认开启，启动后先等待一小时，每轮结束再等待一小时；可在系统设置修改范围、间隔或关闭。扫描范围和排除目录使用统一的多选弹窗，可增删后保存；手动扫描和后台扫描均跳过排除目录及其子目录，新设置从下一轮生效。排除不删除已有索引，也不限制浏览或媒体处理。扫描只更新文件列表，处理由手动操作或已启用计划触发。

## 数据、安全与部署

- **删除文件或目录是永久删除，不进回收站，也不能通过改名历史恢复。** 改名还原也要求文件身份、内容和操作链仍匹配；重要媒体应有独立备份。
- SQLite 数据目录必须在本机磁盘，不能放 SMB/NFS；同一个数据库只运行一个实例。媒体目录可以是网络挂载，实际吞吐和文件身份行为需要在目标环境验证。
- 停止服务后备份完整 `storage` 目录，数据库与 `data.sqlite.key` 必须一起保留。缓存可以重建。恢复旧备份后先核对期间发生的文件改动。
- 仅本机使用时保留默认监听地址。局域网访问可改为 `0.0.0.0`；远程访问使用 HTTPS 反向代理，限制入口访问并保留原始 Host。不要把管理员工作台直接暴露到不受信任网络。
- 模型命名会把视频截图和提示词发送到你配置的模型地址，可能产生费用；不会上传原视频。密钥加密存储，管理员应只配置受信任的服务。

项目尚未上线，不提供旧数据库迁移或旧配置兼容。不受支持的数据库会拒绝打开并保留原样；需要重建开发实例时，明确选择新的 `storage` 目录。
