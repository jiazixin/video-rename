### 核心回归

改名 → 再次改名 → 父目录改名 → 重启 → 逐次还原；已处理和已还原文件不再调用模型；同名冲突不覆盖；外部替换与符号链接拒绝；手动请求幂等；数据库只读时不改名；文件已改名但最后数据库提交失败时，停止后续提交并可恢复；不确定的恢复阻止关联目录操作；任务取消与分析期间源变化；重复 Cron 触发、计划重叠、时区及夏令时预览。

### 浏览器流程

1. 错误登录提示、正确登录、文件改名、同名冲突、还原、成功 / 失败日志、退出。
2. 惰性子目录、100 条分页、前后翻页、名称降序、搜索和 390px 窄屏。
3. 创建计划、五次时间预览、选择目录、暂停、编辑 Cron、删除。
4. 真实 FFmpeg 抽帧 → 本地可控模型响应 → 自动改名 → 再次运行跳过。

测试数据全部由 fixture 在临时目录创建并清理，没有修改用户真实视频。自动命名没有借助 mock 改名接口绕过文件系统提交。

## 性能测量

合成数据：5,000 个目录，每个含 10 个文件；另外一个目录含 50,000 个文件。所有文件都是隔离的小型占位媒体文件，压力测试不请求模型。

| 场景 | 最新结果 |
| --- | --- |
| 5,001 个直属目录建立索引 | 约 243ms |
| 单目录 50,000 文件建立索引 | 约 3.82s |
| 已有索引，每页 100 条，连续查询 30 页 | P95 约 6.7ms |

结果来自当前本地文件系统，不能外推为 NAS、机械盘或真实模型吞吐；浏览和索引不读取视频内容或生成缩略图。
