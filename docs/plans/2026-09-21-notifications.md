# 批次通知实施计划

目标：新增“通知设置”，支持企业微信、Telegram、钉钉、Bark 和通用 Webhook，发送批次结束摘要。

1. 数据库迁移：通知渠道、发送队列与实际开始时间；渠道凭据复用数据库加密。
2. 独立通知 worker：读取保存设置后新建的终态批次；持久队列去重、有限重试，失败不修改任务状态。关闭渠道停止发送。
3. 适配器：按官方协议组装纯文本消息，钉钉支持加签；超时、响应业务码校验、禁止重定向、错误不回显凭据。
4. 管理 API 与页面：每渠道启用/仅失败/保存/测试，敏感字段留空保留；展示最近发送记录。无需真实凭据即可完成模拟测试。
5. 验证：Go 适配器/队列/加密测试、前端构建、隔离浏览器配置测试；更新 README 与开发说明。

通知内容：批次 ID、状态、来源、目录、模型、总数、成功/跳过/失败/未完成数、提交/实际开始/结束时间与耗时。不会发送视频、截图、模型密钥或提示词。
