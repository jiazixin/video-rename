# 图片编号与整批还原

已确认：只处理当前目录图片视图的搜索匹配结果，跨页且沿用当前排序。保留已有正整数编号（规范化前导零），所有图片格式共用数字；重复编号按视图保留第一张，其他图片与杂乱名称按视图顺序从最大编号之后续排。扩展名小写，不补空号。未参与的编号图片也保留其号码，避免筛选制造新重复。

实施：
1. 服务端生成并持久化预览，冻结顺序、文件身份与目录指纹；确认时重新检查。
2. schema v11 保存批次、文件映射和逐步移动意图。全部改动文件先转唯一临时名，再转最终名称；不覆盖目标。
3. 成功后在同一数据库事务中提交文件索引、原名到最终名的历史和批次状态。失败及启动恢复走两阶段回滚；证据不一致时标记待核对并阻止相关目录继续修改。
4. 图片视图提供“一键编号”和“编号记录”，预览分页；从记录可预览并整批还原，刷新后仍可访问。
5. 验证编号规则、过滤与跨页排序、冲突/过期预览、幂等、失败及重启恢复、整批还原、界面流程与构建。
