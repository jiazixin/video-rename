# Web 抽帧设置实施计划

目标：抽帧与图片参数只在 Web 管理，不读取或导入 YAML 中的 sampling/images。

设计：新增独立抽帧设置页，沿用工作台样式、表单和下拉组件。SQLite 单行保存全局设置；复用媒体校验逻辑；创建批次时保存独立参数快照，执行时恢复。默认沿用程序内置 hybrid / 12 帧 / 768 像素 / JPEG 4，可在页面调整。

1. config 将 sampling/images 标为运行时字段，提取共享校验入口，不做兼容、导入或专门迁移提示。
2. storage 增加设置表与 runs 抽帧快照列；sampling 包负责默认值、读写和快照验证。
3. app 增加受现有认证和 CSRF 保护的 GET/PUT 接口，jobs 创建及执行接入快照。
4. web 新增基础参数、图片参数、动态档位表、加载/保存/错误状态及侧栏入口。
5. 更新配置示例、使用文档和 E2E fixture；覆盖参数校验、持久化、任务隔离及页面保存刷新。
6. 执行前端构建、Go 测试与静态检查、构建和定向浏览器验证。
