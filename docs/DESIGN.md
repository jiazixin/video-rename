# 当前架构与行为

更新：2026-09-27。当前功能入口见 [README](../README.md)，实现细节见 [开发说明](IMPLEMENTATION.md)。目录规则统一引用根 [目录规范](../目录规范.md)。

## 服务形态

应用是 Go 1.27.1 + Vue 3 / TypeScript + SQLite 的单实例 Web 服务，支持 macOS / Linux。前端构建结果通过 Go embed 打包；启动只初始化服务，浏览目录时按需建立索引，处理由手动任务或已启用计划触发。

YAML 只保存监听地址、媒体根目录、持久数据和缓存目录、管理员账号。抽帧、模型、提示词、编号、通知与并发设置通过页面管理。配置严格校验，只接受单个 YAML 文档。模型密钥及任务配置快照使用 AES-GCM 加密，主密钥保存在 storage 目录。

## 页面与数据流

| 页面 | 职责 |
| --- | --- |
| 文件目录 | 惰性索引、搜索分页、媒体播放、手动命名、删除、处理标记、批量抽帧/命名、图片音频编号及还原 |
| 抽帧记录 | 独立抽帧与命名准备阶段的成功/失败记录、缓存命中与媒体诊断 |
| 运行记录 | 文件操作历史、失败重试、请求/响应诊断与名称还原 |
| 计划管理 | 手动提交、定时命名/抽帧、Cron 与时区、暂停及立即运行 |
| 批次记录 | 组合筛选、分页、进度、取消、明细与整批还原 |
| 模型用量 / 运行分析 | 模型 token 账本、请求趋势、批次性能、逐项耗时及失败原因 |
| 系统设置 | 处理与缓存、编号规则、固定提示词与提示词库、模型配置、抽帧和通知 |

前端 API 统一处理认证、CSRF、错误响应与请求取消。目录导航和统计筛选使用请求序号防止迟到响应覆盖；列表的原位状态更新保留已有选择与滚动位置。编辑提示词库时保留独立的固定提示词草稿。

## 处理链

1. 创建运行时验证目标、重复请求键及活动范围冲突。命名任务冻结模型、完整提示词和抽帧配置；抽帧任务无需模型。
2. 扫描真实目录，忽略符号链接，记录文件身份、大小、修改时刻；按设置做稳定性观察。
3. jobs 调度 pipeline.Prepare：ffprobe 探测、计算采样点、FFmpeg 抽帧。全局抽帧并发与缓存容量限制生产速度。
4. 完整截图经身份及内容校验后进入缓存。独立抽帧到此完成；命名任务取得所属模型的共享并发名额后调用 pipeline.Infer。
5. vision 校验响应、截断和单行标题。标题含“命名失败”时记录失败，保留原名。有效标题经 naming 清洗后由 library 执行统一提交。
6. 成功提交后清理对应截图；失败、取消和独立抽帧完成保留完整缓存供重跑。闲置缓存按容量与 72 小时有效期回收，使用中的截图由租约保护。

最多 20 个活动批次可并行扫描和处理。抽帧并发全局共享，模型请求并发按配置 ID 跨批次共享；运行期间只同步并发数，其他参数使用创建快照。普通单视频失败不终止其余条目；取消停止派发并等待在途处理收尾。

预算由 domain、media 和 vision 控制：探测 30 秒、抽帧 120 秒、单图 1 MiB、请求体 16 MiB、响应体 1 MiB。模型调用有限重试；各阶段及队列等待均支持取消。具体协议见 [媒体处理](processing.md) 和 [模型请求](model-request.md)。

## SQLite 结构

唯一建表资源是 `internal/storage/schema.sql`；初始化器在空数据库内事务创建全部表和索引。当前结构标识为 20260927，已有不同结构会被拒绝，不执行迁移、历史回填或重建。需要使用新的 storage 目录，已有数据库和媒体保持原状。

| 数据组 | 表 |
| --- | --- |
| 根目录与索引 | library、entries、directory_state、directory_items |
| 改名与保护 | operations、events、marks、image_numberings、image_numbering_items |
| 任务与计划 | runs、run_items、schedules、schedule_ticks、extraction_records |
| 模型与设置 | model_configs、prompts、sampling_settings、system_settings |
| 统计 | run_token_usage、token_usage_records |
| 认证与通知 | sessions、notification_channels、notification_deliveries、notification_preferences |

数据库使用 WAL、FULL 同步、单连接短事务和实例锁。连接重建时重新启用外键、同步及 busy_timeout。实体 ID 不复用，避免历史引用或已用游标指向新实体。模型配置必须引用存在的提示词；计划保存事务内检查模型引用，模型删除检查计划使用情况。

目录索引先完成新 generation 再切换。分页、排序和汇总读取完整 generation；首次建立索引显示待统计，后台刷新可继续展示上一次完整结果。文件使用设备号、inode、大小和修改时刻核对，路径由受约束的父子条目关系构建。

## 文件修改与恢复

手动命名、自动命名与还原共用 library 提交逻辑：核对根目录和祖先路径、文件快照及目标冲突，先持久化 prepared 操作，再执行平台原子 no-replace 改名及目录同步，最后提交索引、历史与处理标记。不能覆盖已有目标。

还原要求当前身份、内容和操作链仍匹配，逐次撤销最近有效命名。恢复原名时保留原扩展名大小写；手动和自动命名统一使用小写扩展名。批量还原逐项提交，失败项可重试，不提供跨文件事务。

图片与音频编号先生成冻结预览，再用唯一临时名完成两阶段移动。移动前写日志，启动时根据 current/pending 名称和文件身份恢复；证据不一致时进入 review，阻止相关范围继续改名，等待核对。此机制是当前文件安全功能，保留完整实现。

文件删除需要页面确认，目录递归删除不进回收站，不属于改名还原范围。媒体根、活动任务和待核对操作占用的目标不能删除。

## 调度与重启

自动计划使用五段 Cron 和显式 IANA 时区，以计划 ID 和本地时间去重。保存、删除和调度互斥，防止使用过期计划派发；关机错过的时间不补跑。计划或手动任务的范围冲突在任务创建时统一检查。

重启在事务内将活动运行标记 interrupted，并将其未结束明细置为 cancelled、记录完成时间与中断原因；抽帧记录同步收尾。文件操作日志先恢复或标记待核对，再允许新的文件操作。

## 统计口径

模型用量账本按 run item 唯一键幂等写入，单事务累计请求记录与批次总量。优先使用模型 usage，缺失时使用文字估算；估算不含图片 token，模型测试与未记录的内部重试不计入。排行始终按区间 token 排序，明细支持独立排序。

运行分析按实际开始时间（未开始时按提交时间）筛选批次；批次和逐项耗时只使用真实开始、完成时刻，排队中取消不产生执行耗时。区间为 `[from,to)`，趋势按请求时区对齐，支持夏令时。配置选项按 ID 去重，0 表示无需模型的抽帧任务。

## 认证、通知与部署

所有媒体、历史、诊断和业务 API 需登录；写操作校验 CSRF 与同源。会话随机令牌只存哈希，退出立即撤销，认证配置变化使既有会话失效。HTTP 返回的诊断需脱敏并裁剪，不返回密钥或图片负载。

通知队列持久化、按渠道和批次去重，失败最多尝试三次。发送失败不影响命名结果；响应丢失时可能重复送达。具体渠道配置见 README。

数据库应位于本机磁盘，storage 与缓存均在媒体根之外。冷备份需停止服务并保留完整 storage 目录及密钥；在线备份使用 SQLite Backup API。恢复备份后必须核对备份之后的文件变化，应用无法自动回滚外部文件系统。

## 当前 UI 约定：日期时间

日期与时间上下两行显示，统一复用 `web/src/components/DateTime.vue`。日期在上、时刻在下，两行间距由 `--date-time-gap: 4px` 控制；按浏览器本地时区展示，悬停和无障碍文本提供完整时间。空值与无效时间显示“—”。

## 验证边界

单元及集成测试使用临时数据库与合成文件，真实 FFmpeg 验证抽帧，浏览器使用本地假模型。真实模型标题质量、渠道送达与用户媒体未作为自动验收范围。最新命令及结果见 [验收记录](ACCEPTANCE.md)。
