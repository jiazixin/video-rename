# 代码结构与遗留清理记录

目标：核实版本与配置来源，清理确认失效的代码，按实际职责整理入口、大页面和任务模块。起始工作区干净，基于 `8a24c3a`；没有操作用户配置、媒体或运行数据库。

## 版本与事实核实

CLI 和私有 Web 清单原来重复写着 `0.2.0`。Git 虽有 `1.0` / `1.1` 标签，但不能据此把当前开发代码当作某个已发布版本。现在普通构建显示 `dev`，并在 Go 构建元数据可用时展示提交号和修改状态；正式版本由干净标签构建时注入。私有 Web 包不独立发布，不维护另一份产品版本。帮助信息中的旧 YAML `path` 已修正为 `media-path`。

Go 清单与本机工具链均为 1.27.1。npm 锁文件确认 `lucide-vue-next@0.468.0` 已废弃；依据 [官方迁移说明](https://lucide.dev/guide/vue/migration) 改用 `@lucide/vue@1.52.0`，锁文件比较确认其他依赖版本、完整性与来源均未改变。该依赖仍承担图标渲染，处理方式是迁移而不是删除功能。

## 保留项及依据

- 数据库结构标识、缓存命名空间、编号快照版本各有持久化或恢复含义，不能当作产品版本残留删除。
- 文件身份/内容校验、崩溃恢复、游标与 generation、任务暂停/重试均有实际运行调用及回归覆盖。未发布项目不支持旧数据库，不等于可以删除当前数据库内未完成操作的恢复能力。
- `Manager.Analyze` 是现有任务测试的注入点，用于稳定模拟失败、取消与模型快照；不是旧部署配置或旧协议入口。本次保留与 Prepare/Infer 一起使用的测试接口。
- 共享主题仍包含多页面共同使用的表格、弹窗、状态和布局样式；没有按行数或简单类名搜索盲删。目录页保留列表导航和协调职责，不为降低单文件行数再引入另一套控制层。
- 23 个 internal 包的依赖未发现反向引用 app/cmd；共享 components/lib 未引入 features。未发现需要另做全仓目录迁移的证据。

这是基于源码、调用关系和回归的整理结果，不是对“全仓永远不存在任何死代码”的形式化证明。浏览器默认仍为串行共享服务器，已修复本次确认的顺序依赖，不宣称任意测试都具备独立并行夹具。

## 验证方式

执行 Web 格式/类型/构建，Go 全量测试、竞态、vet、依赖校验、FFmpeg 集成及原生/Linux交叉构建；浏览器验证独立用例和完整套件。使用包含工作区变更、无 Git/依赖/产物的临时源码副本验证冻结安装与构建。具体结果、失败修复和未执行项见 [验收记录](2026-10-05-acceptance.md)。
