# 批次详情完整记录刷新计划

**目标：** 运行日志和失败记录独立读取整个批次，自动更新最新结果，并保留文件清单原有分页。

**实现：** 扩展现有批次条目接口，提供处理日志和失败记录两种查询，每页 100 条，按最近处理时间倒序。前端为两个折叠区各自管理页码、刷新、取消请求和错误提示；展开且页面可见时刷新，第一页展示最新，历史页保留页码。

**技术栈：** Go / SQLite、Vue / TypeScript、Playwright。

1. 为条目接口增加记录视图查询、批次内过滤、时间排序与分页；保留文件清单查询行为，不修改数据库结构。
2. 加入接口测试，覆盖超过 100 条的数据、非当前文件页的失败、新结果插入、批次隔离、页码收敛和无效查询。
3. 在批次详情加入共用刷新逻辑和独立日志/失败分页；请求取消和序号防止迟到覆盖，读取失败保留已有记录并提示重试。
4. 加入浏览器测试，核实全批次记录、自动刷新、独立分页、展开状态及窄屏；更新原有详情测试的接口夹具。
5. 执行格式检查、前端检查/构建、Go 测试和构建、受影响浏览器测试，并检查改动范围。
