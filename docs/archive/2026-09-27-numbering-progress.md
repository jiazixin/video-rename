# 目录编号进度与取消实施计划

**目标：** 右上角目录编号使用短请求反馈进度，预览后仍须确认；关闭编号弹窗取消处理。

**方案：** 应用层管理短期编号任务，提交立即返回，查询续租。显式取消或页面停止查询后取消任务。预览与执行使用可取消上下文，执行失败或取消沿用现有日志回滚当前目录，已完成目录保留。预览结果分页返回。无需变更数据库结构或外部通知。

## 步骤
1. 在 internal/library/numbering.go 与 numbering-tree.go 增加可取消入口及进度回调，保留原有调用入口。
2. 在 internal/app/numbering_jobs.go 实现幂等提交、状态、分页结果、取消和页面租约；app.go 负责关闭时等待安全退出。
3. 在 web/src/features/library/DirectoryNumbering.vue 接入任务查询；关闭、离页时取消，禁止自动确认；抽取同域编号请求逻辑。
4. 后端验证请求立即返回、预览不改名、重复提交、取消、租约到期、部分目录成功后停止、当前目录回滚；浏览器验证进度、确认、关闭取消与分页。
5. 运行前端构建、相关 Go 测试/race/vet、目录编号浏览器回归，更新 README 和开发说明。

## 边界
状态为进程内短期数据，重启不续跑任务；已执行编号日志仍用于恢复与还原。取消不能打断正在进行的单次文件系统调用；调用返回后检查取消并安全恢复。
