# Web 运行、改名与恢复

## 文件浏览

SQLite 中的目录索引是展示缓存，真实文件系统是最终事实来源。首次进入只枚举当前层，每批 128 条，完成后发布目录版本；50 / 100 / 200 条分页使用稳定排序键和条目游标。游标对应的目录版本变化时，返回第一页重新加载。默认新鲜期 30 秒，支持手动刷新，符号链接显示但不可进入或操作。

目录名字改变只更新父子映射中的 basename，不改写所有子文件的历史路径。根目录自身不能改名。长路径、重复进入和深层目录都通过条目 ID 关联。

## 手动命名和还原

文件与目录手动改名均通过同一个提交协调器。提交前核验条目版本、真实身份以及文件 size/mtime；视频保留扩展名。非法 basename、同名目标、源替换、活动任务占用都拒绝操作。

还原撤销最近一次尚未撤销的改名，可逐次还原到最初名称；不提供重做或任意历史跳转。还原只恢复当前条目的 basename，不撤销其中子文件的独立改名。已有同名目标时拒绝还原，不覆盖、不添加后缀。

成功手动命名或自动命名文件后，SQLite 保存设备/inode、size/mtime 和操作关联标记；还原后清除该文件的保护标记，可再次自动命名。仅命名文件夹不会把子文件全部标记为已处理。外部替换、复制或内容变化不是全内容哈希去重；疑似版本变化的文件会重新接受稳定性检查。

## 自动运行

手动运行、单视频自动命名、目录批次和计划触发都使用 SQLite 任务队列。服务启动不直接运行，也不补跑停机错过的计划。

每个批次先分层扫描，候选持久化后才开始处理；同批次按文件身份去重。已保护文件在扫描与执行前检查并跳过；无待处理候选时不等待稳定性观察。其余候选至少等待 30 秒再核验 size/mtime，期间变化的文件留待下次。

一个批次运行，最多 20 个待运行批次；视频并发跟随批次原模型配置的最新 workers（1–32），每次最多预读 128 条待处理明细，仅在有并发空位时启动。运行中约每 500 毫秒检查并发修改，降低时等待在途任务完成，不中断请求。FFmpeg、图片和模型预算沿用已有规则。所有成功提交使用平台原子 no-replace；自动命名遇到目标冲突时按已有规则追加后缀。

取消会停止领取并取消媒体 / 模型请求；进入提交临界区后先完成记账。刷新或关闭浏览器不会取消后台任务。服务器重启将前次未完成批次标记中断，再利用成功标记避免重复处理。

## 运行计划

支持每小时指定分钟、每日时刻、每周多个星期与五段 Cron。时区显式保存，默认 Asia/Shanghai，提供未来五次执行预览。Cron 为分、时、日、月、周，日与周同时受限时为 OR 语义；不支持秒字段和宏表达式。

触发键防止同一日历时刻重复创建；夏令时回拨重复本地时刻只运行一次。前一批次未结束时跳过新的到期触发，不持续堆积。暂停只影响未来触发，删除计划保留历史及正在运行的批次。

计划引用目录 ID，软件内改名后可以继续定位。目录外部替换或挂载变化不得静默改为处理同名新目录。

## 任务历史与故障恢复

成功和失败是 events 的两个独立查询类别；跳过和取消属于运行统计。改名事务先持久化 prepared，再调用无覆盖改名并同步父目录，最后提交当前映射、历史、处理标记和成功事件。

SQLite 与文件系统并非一个事务。重启恢复时：

- 源仍匹配且目标不存在：标记中断未提交。
- 源已消失且目标身份和版本匹配：补全成功记录和保护标记。
- 两边都存在、都不存在或证据不符：待核对，不能只凭目标存在认定成功。

数据库写失败后停止新文件提交，已经改变的名称不盲目反向恢复。人工核对 unresolved 操作前，不能删除数据库或手动清空标记规避检查。

SQLite 使用本地磁盘与 WAL，单实例文件锁防止多个调度器使用同一数据库。数据库不保存视频内容、截图或明文登录密码。模型 API key 与任务模型快照使用 AES-GCM 加密保存；数据库旁的 `<storage>/data.sqlite.key` 文件权限为 0600，必须和数据库一起备份、恢复。历史路径是敏感本地信息，只向已认证管理员提供。

停止服务后可冷备份状态目录；在线备份使用 SQLite Backup API。恢复旧数据库备份之后需人工核对磁盘状态并暂停计划，应用无法推断备份时间之后丢失的历史事件。
